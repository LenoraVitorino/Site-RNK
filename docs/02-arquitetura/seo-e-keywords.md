# SEO, keywords e performance

## Requisitos técnicos

- **Velocidade < 2,5s** (Core Web Vitals: LCP, FID/INP, CLS)
- **Mobile-first** (Google indexa pela versão mobile)
- SSL (HTTPS), **sitemap XML**, **robots.txt**
- **Schema markup**: Organization, LocalBusiness, FAQ, BreadcrumbList
- **URLs limpas e hierárquicas** (`/studio/revena-start`)
- Hosting de qualidade

## Estrutura de conteúdo

- Uma **H1 por página** (com keyword principal)
- Hierarquia H1 > H2 > H3
- Parágrafos curtos (3–4 linhas máx.)
- **Internal linking** forte entre páginas
- Cada página responde **UMA** intenção de busca

## E-E-A-T — o que prova expertise

- Equipe visível (CEO, time)
- Cases com números reais
- Logos de clientes + depoimentos
- Conteúdo autoral com perspectiva própria
- Certificação GPTW

## Preparação para AI Overviews (2026)

- Respostas diretas em formato pergunta/resposta (FAQ)
- Definições claras ("O que é RevOps? É...")
- Dados citáveis (números específicos)
- Conteúdo de experiência real que IA não replica

## Estratégia por faixa

| Faixa | Onde | Racional |
|---|---|---|
| **Alto volume + alta concorrência** | Home | Captura tráfego de quem busca agência e diferencia logo de cara |
| **Volume médio + concorrência média** | Páginas de produto | Ranqueiam mais fácil com conteúdo específico |
| **Baixo volume + zero concorrência** | Blog + categoria nova | Território virgem. Quem escrever primeiro, domina. É aqui que a Renke cria a categoria "RevOps para clínicas" no Google brasileiro. |

> ⚠️ A home declara "FAQ (4 perguntas)" no schema, mas o briefing **não traz uma seção de FAQ na
> copy da home**. Ou se cria a seção, ou o schema precisa vir de outra página.

## Checklist resumo

- [ ] Velocidade < 2,5s, mobile-first, hosting bom
- [ ] H1 com keyword, meta descriptions únicas, schema
- [ ] Conteúdo que responde intenção de busca com prova de expertise
- [ ] 1 CTA por página, prova social, objection handling
- [ ] Cases reais, números, equipe visível
- [ ] Blog pra SEO de longo prazo (educar sobre RevOps, atrair tráfego orgânico)
