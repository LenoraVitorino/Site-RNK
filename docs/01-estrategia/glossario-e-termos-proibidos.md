# Glossário de tradução e termos proibidos

> Este documento é o **filtro de linguagem** do projeto. Antes de publicar qualquer texto voltado a
> clínicas, passe por aqui.

## 🚫 Termos proibidos na comunicação para clínicas

- Alavancas de geração de receita
- Revenue Operations as a Service (ROaaS)
- **Arquitetura de receita** ← termo morto (médico entendeu que éramos arquitetos)
- Inteligência analítica aplicada mensalmente
- Maestro que transforma ruído em sinfonia
- Transformação digital
- Soluções inovadoras
- Comoditizando
- SLAs
- Fonte única de verdade
- Martech

## Glossário de tradução (CEO → Médico)

| O que o CEO escreve | O que o médico entende |
|---|---|
| Controle das alavancas de crescimento | Saber o que está funcionando e o que está travando seu faturamento |
| Maturidade de negócio | Uma clínica que funciona sem depender só de você |
| Alavancas não conversam entre si | Marketing traz gente, mas o comercial não fecha. Ou fecha, mas o paciente não volta |
| Dados fragmentados | Cada ferramenta mostra um número diferente e ninguém sabe qual é o real |
| Metodologia proprietária | Um método nosso, testado em X clínicas, que já gerou Y em resultado |
| Tecnologia embarcada no serviço | A tecnologia já vem dentro, você não precisa contratar mais nada |
| Interpretação de dados com contexto | A gente não entrega relatório, entrega decisão |
| Ecossistema integrado | Tudo conectado: do anúncio ao retorno do paciente |
| Crescimento desordenado | Faturando mais, mas lucrando igual (ou menos) |
| Tracionar exponencialmente | Dobrar a aposta no que está dando certo |

## Termos do Core que NÃO vão pro site

| ❌ Não usar | ✅ Usar |
|---|---|
| Circuito fechado de RevOps | Marketing e comercial se alimentando um do outro |
| Acionáveis reais para o negócio | Recomendações claras do que fazer |
| Controlar as alavancas de crescimento | Saber onde investir mais e onde parar |
| Inteligência de performance | Entender o que realmente funciona |
| Omnichannel | Em todos os canais que fazem sentido |
| CPL, ROAS, CPAg | Usar só em relatório, não em comunicação de venda |
| Ativos de conversão | Anúncios e páginas que fazem o paciente agendar |
| Backlog de públicos vencedores | Banco de audiências que já deram resultado |

> **Nota:** a cadeia de dependência técnica (tracking → CRM → aderência → dados → inteligência →
> decisão) é ótima pra Academy. Pro site da clínica, a versão é:
> *"Cada etapa alimenta a próxima. Por isso exigimos que a base esteja construída antes de operar.
> Sem isso, seria mais uma agência otimizando no escuro."*
